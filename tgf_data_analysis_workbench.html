Each rule first creates a preview. Review the proposed changes before applying. Rules affect the working copy only.

Normalize common missing markers

Convert exact tokens such as N/A, NA, NULL, and — to blank cells. Review before applying because meanings depend on context.

Population standard deviation describes spread when the uploaded values are treated as the whole group being analysed. A sample standard deviation uses a different denominator (n − 1), so do not mix the two.

T5 · Charts and IQR outliers

Numeric columns produce a histogram and an inclusive-quartile IQR check. Text columns produce a frequency chart. The IQR fences are calculated once from all valid numeric values and reused when comparing the full data with the in-fence data.

Distribution chart

Choose a column to draw a chart.

IQR analysis

Choose a numeric column to calculate quartiles and fences.
IQR details will appear here.

Outlier comparison · same fences

The “with outliers” and “without outliers” summaries use the same lower and upper fences calculated from the full selected column. Records outside the fences are flagged, not automatically deleted.

Comparison will appear here for numeric data.
